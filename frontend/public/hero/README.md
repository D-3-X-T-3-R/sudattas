# Hero images

Place your 4 hero photos here with these **exact filenames**:

| File        | Your photo              | Position  |
|------------|--------------------------|-----------|
| `left.png` | Red saree (glasses)      | M1 – left |
| `center.png` | Cream saree            | HERO – center (dominant) |
| `right1.png` | Floral saree (maroon/batik) | M2 – right 1 |
| `right2.png` | Black floral saree     | M3 – right 2 |

**Formats:** `.png` or `.webp` both work. If you use WebP, name them `left.webp`, `center.webp`, `right1.webp`, `right2.webp` and update the paths in `src/lib/seed-data.ts` to use `.webp`.

**Tip:** For best performance, export at about 2560×1440 and keep each file under ~450 KB (WebP quality ~80).
