# Journal collage images

Placeholders are currently in here (reused hero photos) so the mosaic has something to render. Replace them with your real journal photography using these **exact filenames**:

| File             | Position in the collage     |
|------------------|------------------------------|
| `journal-1.png`  | Top-left tile                |
| `journal-2.png`  | Mid-left tile (overlaps #1)  |
| `journal-3.png`  | Center tile                  |
| `journal-4.png`  | Top-right tile                |
| `journal-5.png`  | Bottom-right tile (overlaps #4) |

**Formats:** `.png` or `.webp` both work. If you use WebP, rename to `journal-1.webp` etc. and update the paths in `src/components/journal-teaser-section.tsx`.

**Tip:** Portrait-leaning crops (roughly 3:4) work best since the tiles are taller than they are wide.
